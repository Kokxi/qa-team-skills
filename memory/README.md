# 记忆模块（Memory Module）

## 定位

记忆模块是 qa-team-skills 的**持久化层**，负责在多次任务执行间沉淀和复用测试资产：

- **用例库**：历史生成的测试用例，可按模块/类型/方法检索复用
- **缺陷库**：历史缺陷分析结果，支持根因归类、趋势分析
- **评审库**：历史需求评审结果，问题清单可转化为用例
- **报告库**：历史测试报告，支持同比/环比趋势
- **规范库**：团队测试规范、Checklist、经验教训

## 架构

```
memory/
├── README.md              ← 本文件：模块说明
├── schema/                 ← 数据模型定义
│   ├── review.json         ← 评审记录模型
│   ├── test-case.json      ← 测试用例模型
│   ├── bug.json            ← 缺陷记录模型
│   ├── report.json         ← 报告记录模型
│   ├── task-session.json   ← 任务会话模型
│   └── standard.json       ← 测试规范模型
└── data/                   ← 实际存储目录（由 AI 在任务执行中创建）
    ├── review/             ← 评审记录 JSON 文件
    ├── test-case/          ← 用例库 JSON 文件
    ├── bug/                ← 缺陷库 JSON 文件
    ├── report/             ← 报告库 JSON 文件
    └── session/            ← 会话记录 JSON 文件
```

> `data/` 目录不在版本库中，由 AI 在首次写入时自动创建。
> 多人协作时，各成员独立维护本地的 `memory/data/`。

## 数据模型

每个库的 JSON Schema 定义了存储结构。AI 在执行指令后按 Schema 结构化输出存入对应文件。

### 核心字段（所有库共有）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 唯一标识，格式：`{库前缀}-{日期}-{序号}` |
| `created_at` | string | 创建时间（ISO 8601） |
| `module` | string | 所属产品/模块 |
| `source` | string | 来源 session_id |
| `tags` | string[] | 自定义标签，方便检索 |

### 各库特有字段

详见 `schema/` 目录下各 JSON Schema 文件。

## 读写规则

### 写入（由 /qa 统一入口触发）

每执行完一个指令步骤，AI 自动将输出结构化存入对应库：

```
## 记忆写入
- 记忆库：review
- 条目 ID：review-20260630-001
- 产品/模块：支付模块
- 摘要：发现 8 个问题（高:3 中:3 低:2），业务分层建议：核心层
```

### 读取（由 /qa 统一入口在步骤执行前触发）

在开始新步骤前，AI 检查记忆库中是否有可复用的数据：

- 精确匹配：相同 `module` + 最近 `created_at`
- 模糊匹配：相同 `tags` 或 `module` 关键词包含
- 读取结果注入到当前指令的输入上下文

## 存储方式

采用**文件级持久化**：

- 每个会话（单次任务执行）生成一个 JSON 文件
- 文件命名：`{库名}-{日期}-{序号}.json`
- 文件位置：`memory/data/{库名}/`
- 推荐工具：AI 直接读写 JSON 文件，无需外部数据库

### 文件内容结构

```json
{
  "session_id": "session-20260630-001",
  "created_at": "2026-06-30T10:00:00Z",
  "entries": [
    { ... 条目内容，符合对应 Schema ... }
  ]
}
```

## 检索方法

AI 在 `/qa` 的任务编排中按以下优先顺序检索：

1. **当前会话**：本 `session_id` 上一步的输出（多步任务）
2. **同模块最近记录**：相同 `module`，按 `created_at` 降序取最近 1 条
3. **全局搜索**：匹配 `tags` 或全文检索 `module` 关键词
4. **无匹配**：按标准 Prompt 执行，不注入记忆上下文

## 生命周期

| 操作 | 时机 | 说明 |
|------|------|------|
| 创建 | 每次 `/qa` 任务执行 | 自动生成 session_id |
| 写入 | 每个指令步骤完成后 | 自动结构化存入对应库 |
| 读取 | 每个指令步骤开始前 | 自动检索，注入上下文 |
| 清理 | 手动 | 删除 `memory/data/` 下的过期文件 |
